# 🌐 Redes de Computadores para Cibersegurança

Conceitos fundamentais de comunicação, camadas e portas lógicas.

---

## 🚪 Principais Portas e Protocolos

| Porta | Protocolo | Descrição / Uso |
|---|---|---|
| 21 | FTP | Transferência de arquivos (inseguro / texto claro) |
| 22 | SSH | Acesso remoto seguro via linha de comando |
| 53 | DNS | Resolução de nomes de domínio em IPs |
| 80 | HTTP | Tráfego web não criptografado |
| 443 | HTTPS | Tráfego web criptografado com TLS/SSL |
| 3389 | RDP | Acesso remoto com interface gráfica (Windows) |

---

## 🧱 Modelo OSI vs. TCP/IP
- **Camada 7 (Aplicação):** Onde os apps interagem (HTTP, DNS, SSH).
- **Camada 4 (Transporte):** TCP (orientado a conexão, confiável) vs UDP (rápido, sem handshake).
- **Camada 3 (Rede):** Endereçamento IP e roteamento de pacotes.
